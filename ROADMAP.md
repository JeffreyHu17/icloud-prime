# Roadmap

This roadmap is intentionally small and issue-driven.

## Near Term

- Add more tests for account parsing and API handlers.
- Improve setup documentation with screenshots.
- Improve Windows portable package verification.
- Improve error messages for expired Cookie values.

## Future Ideas

- Add import helpers for browser-exported Cookie JSON.
- Add better diagnostics for `icloud.com.cn` accounts.
- Add safer redaction for debug logs.
- Add optional Docker examples.
- Add more release artifacts for Linux and macOS.

## How to Influence the Roadmap

Open a feature request issue and explain:

- the user problem
- the current workaround
- the expected behavior
- whether you can help test or implement it
