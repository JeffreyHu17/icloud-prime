# Code of Conduct

## Our Pledge

We want iCloud Prime to be a respectful and productive open-source project.
Participants are expected to be welcoming, patient, and constructive.

## Expected Behavior

- Use welcoming and inclusive language.
- Respect different experience levels.
- Focus feedback on the code, documentation, or user workflow.
- Accept maintainer decisions gracefully.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing another person's private information.
- Posting real credentials, Cookie values, or account data.
- Repeated off-topic or disruptive comments.

## Enforcement

Maintainers may edit, hide, or delete comments and may block users who violate
this code of conduct. Reports can be made through GitHub issues or directly to
the repository maintainer through GitHub.
