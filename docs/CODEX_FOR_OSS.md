# Codex for Open Source Notes

This project is prepared for open-source collaboration and Codex-assisted
maintenance.

## Public Project Signals

- Public GitHub repository: `forever94yu/icloud-prime`
- Open Issues for bug reports, feature requests, questions, and documentation
- Open Pull Requests from forks
- GitHub Discussions for user support and roadmap discussion
- CI workflow for push and pull request validation
- Tagged releases with downloadable Windows portable assets

## Maintenance Workflow

Codex can help with:

- summarizing new issues
- drafting reproduction checklists
- reviewing pull request diffs
- suggesting tests for bug fixes
- updating documentation
- preparing release notes

Maintainer review is required for final decisions.

## Security Boundary

Codex-assisted work must never include real iCloud credentials, Cookie values,
App-specific passwords, or local account files.
