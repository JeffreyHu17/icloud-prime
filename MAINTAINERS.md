# Maintainers

Primary maintainer:

- [@forever94yu](https://github.com/forever94yu)

## Maintenance Responsibilities

- Triage new issues.
- Review pull requests.
- Keep releases reproducible.
- Keep sensitive data out of the repository.
- Keep documentation current.

## Release Process

1. Ensure CI is green.
2. Update `CHANGELOG.md`.
3. Create a version tag.
4. Generate release notes.
5. Upload the Windows portable package.

## Codex-Assisted Maintenance

Codex may be used to help with issue triage, pull request review, test planning,
documentation updates, and release preparation. Maintainer review remains
required before merging or publishing changes.
